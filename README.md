🧪 Kaboom Playtime Pro – QA & Business Analysis
📌 Descripción

Proyecto real desarrollado para Kaboom Bogotá, una plataforma web diseñada para centralizar la administración integral del negocio.

Participé liderando el análisis funcional, el levantamiento de requerimientos, la validación de procesos y las pruebas QA/UAT para asegurar que la solución respondiera a las necesidades operativas y comerciales.

Digitalizar y centralizar los procesos administrativos, comerciales y operativos de Kaboom Bogotá mediante una plataforma web que facilitara la gestión del negocio y apoyara la toma de decisiones basada en datos.
